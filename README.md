# MolStr

A lightweight, privacy-focused, decentralized Nostr client built with Flutter for Android, iOS, macOS, Linux, and Windows.

## Core Pillars

- **Decentralized & Censorship-Resistant:** User-controlled relays, zero middleman servers, no analytics/tracking.
- **Privacy-First:** Minimal metadata leakage. No 3rd-party tracker SDKs.
- **Nostr Games Showcase:** Dedicated discovery hub for games built on Nostr (NIP-89 kind 31990) with direct developer zapping and tipping.
- **Payments:** Bitcoin Lightning zapping via Nostr Wallet Connect (NWC / NIP-47) + Monero tipping.
- **Multiple Signers:** Amber support on Android; local keys and remote NIP-46 signers.
- **Identity:** NIP-05 profile verification support.
